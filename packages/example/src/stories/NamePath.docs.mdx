# `NamePath` 路径系统

## 介绍

`NamePath` 采用了 `@formily/path` 的路径系统，作为 `@event-chat/core` 依赖项用于匹配事件名。因此 `NamePath` 开箱即用，包括 `@event-chat/antd` 也同样支持路径系统。

**用途**：

- 支持相对路径查找，广泛匹配多个事件名批量发送，取反路径排除接收事件等；
- 和 `formily` 不同的是，路径系统在 `eventChat` 中只用于匹配事件名，不支持手动 `setIn` 和 `getIn`。

**2 套路径系统**：

- `@event-chat/core` 集成了 `@formily/path`，因此默认支持 `formily` 的路径系统；
- 而 `Antd` 是数组层级路径，为了相互兼容会统一转换为 `formily` 点路径系统进行匹配。

**3 层路径缓存**：

按照操作顺序如下，目的为了减少路径计算的性能消耗。

## 写在前面

**路径不支持解构表达式**

在 `formily` 中解构表达式用于赋值和取值用的，例如官方文档示例：

```typescript
import { FormPath } from '@formily/core'

const target = {}

FormPath.setIn(target, 'parent.[aa,bb]', [11, 22])
console.log(target) //{parent:{aa:11,bb:22}}
console.log(FormPath.getIn(target, 'parent.[aa,bb]')) //[11,22]
console.log(FormPath.parse('parent.[aa,bb]').toString()) //parent.[aa,bb]
```

而 `EventChat` 使用路径仅用于匹配事件名，不需要赋值和取值。而解构表达式无法匹配路径：

```typescript
import { FormPath } from '@formily/core'

console.log(FormPath.parse('target.[aa,bb]').match('target.[aa,bb]')) //true
console.log(FormPath.parse('target.[aa,bb]').match('target.aa')) //false
console.log(FormPath.parse('target.[aa,bb]').match('target.bb')) //false
```

**仅支持路径解析和匹配**

- `Path.parse`：解析路径，包含计算相对路径
- `Path.match`：用于路径表达式匹配 `eventBus` 中记录的事件名，触发回调事件

1 维路径：

- `formily` 和 `Antd` 都支持，例如：`aa`、`bb`、`cc`
- 在 `Antd` 中还可以通过数组定义：`['aa']`

多维路径：

- `formily` 使用的 `.` 间隔的字符路径：`aa.bb.cc`
- `antd` 使用的数组路径：`['aa', 'bb', 'cc']`

对于数组类型的路径，最终会转换成字符类型，例如：

- `['aa', 'bb', 'cc']` 等于 `aa.bb.cc`

支持 2 个类型：

- `formily` 字符下标路径：`aa.0.bb` 或 `aa[0].bb` 都符合下标路径，且这两条路径在 `formily` 中是相互匹配的
- `Antd` 数组下标路径：`['aa', '0', 'bb']` 或 `['aa', 0, 'bb']` 都符合下标路径，但这两条路径不能相互匹配

数组路径下标转换：

- 下标路径为数值，如：`['aa', 0, 'bb']` 转换为 `aa[0].bb`
- 下标路径为字符，如：`['aa', '0', 'bb']` 转换为 `aa.0.bb`

在 `@formily/path` 中 `aa[0].bb` 等价于 `aa.0.bb`，如果需要区分具体路径，可以通过 `callback` 回调参数判断：

- `origin`：当前的接收事件名，配置提供什么得到什么，不解析不转义
- `originName`：触发事件名，触发时填写什么得到什么，不解析不转义

**相对路径：**

使用相对路径调用 `emit` 作为事件名，例如：

```typescript
useEventChat('aa.bb.cc').emit({ name: '.dd' })
// i.e. `FormPath.parse('.dd', 'aa.bb.cc')` equal: aa.bb.dd

useEventChat('aa.1.cc').emit({ name: '..[].dd' })
// i.e. `FormPath.parse('..[].dd', 'aa.1.cc')` equal: aa.1.dd

useEventChat('aa.1.cc').emit({ name: '..[+].dd' })
// i.e. `FormPath.parse('..[+].dd', 'aa.1.cc')` equal: aa.2.dd

useEventChat('aa.1.cc').emit({ name: '..[+10].dd' })
// i.e. `FormPath.parse('..[+10].dd', 'aa.1.cc')` equal: aa.11.dd
```

> 注册事件时可以提供相对路径作为事件名，但不建议，因为违背了 `@formily/path` 路径规则，无法匹配。

根据不同的路径类型，分别做如下处理：

- `formily` 字符路径：需要手动转义，例如 `aa.\\\\,.bb`
- `Antd` 数组路径：自动转义，例如 `['aa', ',', 'bb']` 等同 `aa.\\\\,.bb`

转义的字符包含：`*~[],:.`

> 在 `formily` 中转义符由 2 条斜杆组成 `\\`，由于 `\` 在 `javascript` 中本身就是转义符号，因此这里用了 4 条斜杠 `\\\\`

注意：

- 当手动转义时，请勿注册事件名时填写：相对路径、通配符等特殊符号，会因违背了 `@formily/path` 路径规则，无法匹配；
- 相对路径、通配符等特殊符号是用于 `emit` 触发事件时使用
